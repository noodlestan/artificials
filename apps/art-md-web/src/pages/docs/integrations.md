# Integrations

Art MD is one project among several at Noodlestan. This page links the sibling
projects; the generated [API reference](/docs/api) documents the Art MD packages
themselves.

## Sibling projects

- [Art JS](https://github.com/noodlestan/art-js) — a modular pipeline for authoring,
  validating, and processing Art MD files as modules, including a dev server, tools,
  and a language server.
- [Art Lib](https://github.com/noodlestan/art-lib) — composable units for CLI
  experiences, driven by use cases surfaced in the CLIs under development.

Neither project has documentation yet — for now their repositories are the source of
truth, and each will get its own documentation in time.

## Art MD

- [Art MD on GitHub](https://github.com/noodlestan/art-md) — the language
  specification and the JavaScript libraries documented on this site.
- [API reference](/docs/api) — generated documentation for the five published
  `@art-md` packages.
- [Demo](/codec-demo) — try the codec in the browser.
- [About](/about) — goals and status of the project.
